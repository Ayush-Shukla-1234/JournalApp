# 📓 JournalApp - Full-Stack Firebase Journaling Android App

A feature-rich native Android application designed for personal journaling, thoughts sharing, and media management powered by **Firebase** backend services.

---

## 📱 Features

* **User Authentication:** Secure email and password registration and login handled via **Firebase Authentication**.
* **Cloud Persistence:** Journal entries (title, thoughts, timestamp, author metadata) stored and synced in real-time with **Cloud Firestore**.
* **Media Handling & Image Loading:** Seamless photo selection from local storage with asynchronous image rendering and caching using **Glide**.
* **Modern UI/UX:** Responsive feed layouts built with `RecyclerView`, custom gradient drawables, and card-based post presentation.

---

## 🛠 Tech Stack

* **Platform:** Native Android
* **Language:** Java
* **Backend & Database:** Firebase Authentication, Cloud Firestore, Firebase Storage
* **Image Loading:** Bumptech Glide
* **Architecture & UI:** Android Jetpack, RecyclerView, ConstraintLayout, Material Components
